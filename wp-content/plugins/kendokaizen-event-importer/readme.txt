=== KendoKaizen Event Importer ===
Contributors: kendokaizen
Tags: kendo, events, excel, importer
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 2.0.0

Imports Approved rows from the KendoKaizen Excel event pipeline (.xlsx/.xlsm) into The Events Calendar.

== Usage ==
1. Open Tools > KendoKaizen Import.
2. Upload the current KendoKaizen Excel pipeline workbook.
3. Click Import Approved events.
4. Existing events are matched by event_id and updated rather than duplicated.

Multiple event types are supported without adding combination choices to the public filter.
