## Export storage

Complete WordPress Playground exports contain WordPress core, database state, plugins, uploads and other runtime/generated files. They are intentionally kept outside Git.

Git stores reusable custom source and the documentation needed to identify each reproducible project milestone. The exact Playground filename used for a stable baseline is recorded in `STABLE_VERSION.md`.
